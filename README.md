# UZCYBER — Kiberxavfsizlik akademiyasi

O‘zbek tilidagi kiberxavfsizlik ta’lim platformasining boshlang‘ich frontend versiyasi.

## Ishga tushirish
1. Repozitoriyani yuklab oling.
2. `index.html` faylini brauzerda oching.
3. Yoki VS Code'da Live Server orqali ishga tushiring.

## GitHub Pages
1. GitHub'da `UZCYBER` nomli yangi repository yarating.
2. Ushbu papkadagi fayllarni repository ildiziga yuklang.
3. Repository → Settings → Pages bo‘limiga kiring.
4. Build and deployment: `Deploy from a branch`.
5. Branch: `main`, folder: `/ (root)`, Save.
6. Bir necha daqiqadan so‘ng GitHub Pages manzilingiz tayyor bo‘ladi.

## Fayl tuzilishi
```text
UZCYBER/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Hozir ishlaydigan imkoniyatlar
- Dashboard va sahifalar o‘rtasida navigatsiya
- Laboratoriyalar katalogi, qidiruv va daraja filtri
- O‘quv terminali simulyatori (`help`, `whoami`, `pwd`, `ls`, `date`, `clear`)
- Laboratoriyani yakunlash va XP olish
- Kunlik vazifalarni belgilash
- XP va level progressini hisoblash
- Brauzerda `localStorage` orqali progressni saqlash
- Mobil menyu va qidiruv oynasi

## Muhim cheklovlar
Bu frontend prototip. Hozirgi reyting demo ma’lumotlardan iborat; foydalanuvchi profili faqat shu brauzerda saqlanadi. Haqiqiy ro‘yxatdan o‘tish, serverdagi progress, umumiy reyting va izolyatsiyalangan laboratoriya serverlari keyingi bosqichlarda backend orqali qo‘shiladi.

Barcha mashqlar faqat ruxsat berilgan va maxsus ajratilgan o‘quv muhitida bajarilishi kerak.
